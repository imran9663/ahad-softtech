# AHAD Softtech Requirements Documentation

This package contains the initial implementation-oriented requirements for the AHAD Softtech corporate website and CMS.

## Files

- `REQUIREMENTS.md` — master product requirements and scope
- `WEBSITE-REQUIREMENTS.md` — public website, pages, UX and responsive requirements
- `CMS-REQUIREMENTS.md` — CMS, roles, content models and administration
- `LEAD-REQUIREMENTS.md` — forms, lead capture, pipeline and WhatsApp requirements
- `SEO-REQUIREMENTS.md` — SEO, analytics, performance and discoverability requirements

## Product direction

AHAD Softtech is positioned as an India-based global BPO and technology solutions provider, with priority markets in the USA, UK and UAE.

Primary business objective: qualified BPO lead generation.

## Brand

The supplied AHAD Softtech logo is the visual brand reference. The digital design system should validate final color values against the original brand assets before production.
