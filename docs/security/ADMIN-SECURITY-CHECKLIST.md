# Admin Security Checklist — Phase 1.3

- [ ] Create only required administrator accounts.
- [ ] Keep Super Admin limited to technical administrators.
- [ ] Enable MFA for CMS administrators when supported/configured.
- [ ] Use strong unique admin passwords.
- [ ] Review role permissions after every new content-type.
- [ ] Do not grant Sales access to Recruitment data.
- [ ] Do not grant Recruitment access to Sales leads.
- [ ] Do not expose Lead or Job Application APIs publicly.
- [ ] Protect resume/candidate files from public access.
- [ ] Review inactive users and revoke access promptly.
- [ ] Review API tokens and rotate/revoke unused tokens.
- [ ] Keep production secrets outside Git.
- [ ] Log and periodically review administrative access where supported.
